# Glossary

Use the installation's `.rbtv/config/communication/glossary.md` for names, mistaken spellings, preferred terms and their meanings in typed input, transcripts and documents. Load it when beginning work with these terms, and check it before asking about a word that does not make sense in context. If it is absent, continue without it; absence is not evidence for a guessed correction.

Apply a correction only where its meaning and context fit. Preserve exact identifiers, commands, code and quoted evidence. Link an existing framework definition when it supplies a term's meaning; do not maintain a competing definition in the installation glossary.

Save an explicit owner correction in the glossary in the same turn, preserving earlier entries and relevant context. Create the file if needed. Record the intended term, the mistaken form and the context needed to distinguish it. Do not save an inferred correction as confirmed; ask when the intended name or meaning remains uncertain.

In speech or transcripts, use the speaker's final explicit self-correction. Hesitation alone does not establish a replacement number or date. Ask about names, dates or meaning only when uncertain; do not require a confirmation table before every write.

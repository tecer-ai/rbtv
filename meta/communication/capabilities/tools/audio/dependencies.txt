requests — the HTTP client audio.py calls the ElevenLabs API with; the transcribe verb posts multipart/form-data, which urllib would need a hand-rolled body for. Already present on the box (2.32.5 measured 2026-08-18) — `pip3 install --user --break-system-packages requests` if a machine lacks it (the box's python is PEP-668 externally managed; --user confines the install to ~/.local and touches no OS package).

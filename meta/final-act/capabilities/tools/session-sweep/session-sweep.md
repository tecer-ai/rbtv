# session-sweep

`session-sweep` does the exact steps of the sweep in [Compound](../../methods/compound.md): it finds this session's record, reduces it to the moments a labeler reads, renders it as a transcript for the full tier's checkers, and checks the label files. The reading and the labelling are the sub-agents'; the ruling is the closing agent's. `-h` and `VERB -h` are the interface reference.

## What each verb returns beyond `-h`

- `locate --marker TEXT` searches the records the harnesses on this machine keep, under the user's home folder: Claude Code (`.claude/projects/*/*.jsonl`), Codex (`.codex/sessions/**/*.jsonl`) and OpenCode (its SQLite database, returned as `PATH.db#SESSION`). Inside an Ignite turn (`RBTV_AGENT_HOME` and `IGNITE_CONVERSATION` set) it returns that conversation's `history.md` first, without reading it for the marker, because the current turn is written there only when the turn ends. Several records holding the marker are all printed; the caller picks the one whose `cwd` is its working folder. A harness writes a message to its record after the turn that produced it ends (measured on Claude Code 2.1: a marker written in one turn was absent during that turn's tool calls and present in the next), so the marker is written in one turn and `locate` runs in a later one.
- `extract` keeps every message the user typed (a message starting with `<`, an interruption notice or an injected instructions file is not one), each with up to 1,200 characters of the agent's message before it; a command whose input matches a dangerous pattern or repeats an earlier call with the same input; a tool result whose first or last 600 characters match a refusal or failure pattern (a failure shows at the head or tail of a result; the middle of a long result is file content); the agent's own text matching a workaround pattern; and each `--report` file whole, up to 6,000 characters. The patterns are the constants at the top of the program; a match is a candidate, and the labeler's `none` is the expected answer for a word quoted from a file. In a Claude Code record, events of a sub-agent run inside the session (a sidechain) are kept and marked.
- `transcript` numbers lines across all the records it is given, so a checker's "chunk line" is unambiguous between chunks. Tool inputs are cut at 600 characters and results at 400; the record stays the evidence.
- `check` validates each label file against the chunk it labels: the moment ids, kinds and the label set per kind come from `moments.json`, so a labeler that invented a moment, skipped one or used a label from the wrong kind is named with its chunk.

## Maintenance

- Record formats: the readers were written from observed records of Claude Code 2.1 (`type` user/assistant lines with `message.content` blocks, `promptSource` typed/queued, `isSidechain`), Codex (`response_item` payloads: `message`, `function_call`, `custom_tool_call` and their outputs), OpenCode (tables `message` and `part`, part types `text` and `tool`) and Ignite (`## <ms> owner|assistant` sections, the assistant's as JSON with `replies`). A harness that changes its record shape changes the matching `events_*` reader; the tests carry one fixture per format.
- Everything is written with explicit UTF-8 and read with replacement of undecodable bytes; paths come from `Path.home()` and the arguments; no shell is used. The program runs on Linux and Windows.
- Self-check: `python3 test_session_sweep.py` in this folder runs the fixtures through every verb.

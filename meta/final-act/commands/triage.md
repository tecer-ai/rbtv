name: triage
description: "CONTAINS: the invocation that rules one backlog by the triage method: the value bar, the owner round before any write, and the application of the rulings PURPOSE: the open entries of one backlog ruled by you and the rulings applied; type the backlog (the path of a tasks file, an issues file or a loose-ends file) and, when you have them, your instructions for this run (a custom bar, a ranking scheme, 'don't delete, only re-rank') ALWAYS LOAD WHEN: you want to go through, prune, clean up or re-rank one backlog now DO NOT LOAD WHEN: done entries are to be swept out of a task file, not judged (ask for the archivist of the final-act skill), or the session is closing (say so; the final-act skill runs triage as one part of the close)"
---

Triage the backlog named in the text typed after the command name. Any further text there is the owner's instructions for this run.

If that text names no backlog, stop and say that the next invocation must name one: the path of a tasks file, an issues file or a loose-ends file.

Read [Triage](../capabilities/methods/triage.md) and follow it from its first step to its close.

# triage decisions

Standing decisions about the triage component. Each states the decision and its reason; the triage skill describes the resulting design.

## Triage is a component of its own

Reason: its trigger is a backlog file to rule on, which shares nothing with thinking a subject through (the `reason` component); one description would have to cover unrelated work, and a component named for its one skill states its boundary (owner decision, 2026-10-08).

## Investigation has no skill here

The former `investignosis` skill is retired; the `coordinate` skill's investigate method is the route for finding out what exists in files or code. Reason: owner decision, 2026-10-08; the ignite pack no longer names it.

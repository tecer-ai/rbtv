# `<procedure>` — method

Write the shortest ordered steps that reliably produce the result. Each step names its real input and action. Link a guide exactly where the step needs it, and name how the occupant handles missing input or a failed command.

Do not copy a tool manual into the procedure. A branch needs a condition and an outcome for each arm. An instrument used in a step also appears in `<resources>` and must resolve to a real command or exposure row.

# `<done-contract>` — completion

Each clause states an observable result and how a reviewer can verify it. Cover the required output, missing or malformed inputs, duplicate events where they matter, and the failure route. A claimed pass without the command or evidence is incomplete.

Keep the checks at the task’s scope. An instruction to do work is a procedure step, not a completion check. A criterion tied to one owner or one run belongs in the seat request.

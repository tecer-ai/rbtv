# Tone of Voice

Tone of voice defines how a brand sounds — not what it says. Use it once character and personality
exist and copy needs to be written consistently by more than one person. What the brand says is
`messaging-architecture.md`; this reference owns only how it says it.

## Tone dimensions

Select 3–5 dimensions and place the brand on each 1–5 slider.

| Dimension | Pole at 1 | Pole at 5 | What it affects |
|---|---|---|---|
| Formal ↔ Casual | Structured, conventional | Relaxed, conversational | Word choice, contractions |
| Serious ↔ Playful | Earnest, focused | Light, humorous | Use of levity |
| Humble ↔ Confident | Modest, understated | Assertive, bold | Claim strength |
| Technical ↔ Accessible | Expert vocabulary | Plain language | Assumed knowledge |
| Reserved ↔ Enthusiastic | Calm, measured | Energetic, expressive | Emotional display |
| Respectful ↔ Irreverent | Conventional, polite | Challenging, unconventional | Authority stance |
| Abstract ↔ Concrete | Conceptual, philosophical | Specific, tangible | Example usage |

Scoring: 1 = extreme left, 2 = lean left, 3 = neutral, 4 = lean right, 5 = extreme right. Avoid
defaulting to 3 — neutrality across the board means no personality.

## Archetype starting intuitions

Use as a starting point, not a rule.

| Archetype | Natural tone tendencies |
|---|---|
| Hero / Explorer | Confident, direct, action-oriented |
| Sage / Creator | Thoughtful, precise, inventive |
| Caregiver / Regular Guy | Warm, accessible, supportive |
| Outlaw / Magician | Bold, surprising, transformative |
| Ruler | Authoritative, formal, commanding |
| Innocent | Simple, optimistic, sincere |
| Jester | Playful, irreverent, energetic |
| Lover | Warm, intimate, expressive |

## Scenarios for do/don't pairs

Every venture encounters these; write a do and a don't for each.

| Scenario | Context | Reader state |
|---|---|---|
| Welcome email | First communication after signup | Hopeful, uncertain |
| Error message | Something went wrong | Frustrated, anxious |
| Feature announcement | New capability shipped | Curious, busy |
| Support response | Customer asked for help | Seeking resolution |

## Context adjustments

Tone adjusts by context; personality stays constant.

| Context | Reader state | Typical adjustment |
|---|---|---|
| Marketing (website, ads, social) | Distracted, skeptical | Dial UP aspiration and personality |
| Onboarding (welcome flows, setup) | Hopeful, uncertain | Dial UP encouragement, DOWN complexity |
| Error / support | Frustrated, anxious | Dial UP empathy and directness, DOWN playfulness |
| Documentation (help docs, guides) | Task-focused, impatient | Dial UP precision, DOWN personality |
| Social media | Casual, open | Dial UP personality, allow informality |

Rules: maximum adjustment is ±1 from baseline · personality modulates in intensity, it does not
transform · 1–2 dimensions never shift at all — the non-negotiable core.

## Sample copy

Write 3–5 sentences for each, annotating which dimensions and adjustments were applied:
homepage headline and subhead (marketing) · welcome email (onboarding) · error message for a
payment or data failure (error/support) · feature update (marketing) · customer success story
opening (marketing).

## What a good output contains

- Tone dimensions with slider positions and the rationale for each position.
- A 2–3 sentence voice summary.
- Three do/don't example pairs per dimension.
- Context adjustments across all five contexts, as a matrix.
- The non-negotiable core — the 1–2 dimensions that never move.
- The five sample copy scenarios, annotated.
- Consistency check results against the archetype and the personality facet.

## Pitfalls

1. **Vague descriptions** — "be friendly", "be professional", "be authentic" are claimed by every
   brand and give a writer no calibration. Use slider positions instead.
2. **No context adjustments** — the same playful tone in marketing and in error messages damages
   trust.
3. **Generic examples** — "Hello, valued customer!" teaches nothing. Use the real product,
   terminology, and messages.
4. **Tone before personality** — tone is the audible expression of the archetype and the
   personality facet. Without those, every tone choice is arbitrary.
5. **The guide as a constraint** — if it feels restrictive nobody uses it. Frame it as "here is how
   we sound", not "here is what you must not do".

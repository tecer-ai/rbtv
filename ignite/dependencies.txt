NEVER `npm install js-yaml` unversioned: that resolves whatever is latest that day, which is exactly what task 7.51 closed. 5.2.2 is also the first release OUTSIDE advisory GHSA-pm4m-ph32-ghv5 (high, CVSS 7.5 — denial of service by exponential parse time in flow collections), which covers 5.0.0–5.2.1.

## How it works
`workspace_root` walks parents for `.rbtv/config/`; `rbtv_repo` reads `rbtv.json`'s `rbtv_path`; `register_root` lands on `<ws>/.rbtv/goals/ignite-engine/register` (`REGISTER_REL`) unless `--register` overrides (tests only). `derive_as` walks to a `seat.md`, takes its `seat:` field and the `goals/<goal>/seats/<seat>` path segments so a filer normally omits `--as`. `cmd_file` requires `FILE_FIELDS` (`surface`, `class`, `symptom`, `evidence`, `suggested-action`, `risk`), then `check_register` (must exist and be writable), then `mint_id` as `G-<seat>-<MMDD>-<HHMM>` UTC with collision suffixes `-2`, `-3`. Write is atomic: `.tmp.<id>.<pid>` then `Path.replace` into `register/open/<id>.md`. `render_filing` emits YAML frontmatter (`id`, `filed-by`, `when`, the six fields, `status: open`) plus `## <id> — <symptom>` and `Destination: ignite-engine`. Typed `Refuse` codes include `missing-field:<name>`, `scope-refused`, `register-missing`, `register-not-writable`, `not-found`. Read verbs: `list` (status open/closed/all, optional class), `show <id>`, `doctor` (path, exists, writable, open/closed counts). Classes at this commit: `daemon-crash` `launch-cage` `coordination` `bridge-chat` `probe-gap` `data-ledger` `catalog-meta` `docs` `change-notice` `other`. Usage: `file-issue file --surface ignite/…|meta/… --class <class> --symptom "…" --evidence "…" --suggested-action "…" --risk "…"`. Skill verify step: `file-issue doctor` then `file-issue show <id>`.

## Mechanism
`checkout_disposition` was a three-arm expression: `"renew" if renew else ("incomplete" if incomplete else "done")`. `declared_outputs` already computed `_outputs_note`; a zero-token prose `## Outputs` opened `outputs-undeclarable:…` and that note was written onto the record. Nothing set the local `incomplete` variable, so the expression fell through to `done`. Missing declared *paths* already hard-refused (exit 1, two honest endings offered). No-section-at-all (`none-declared`) was deliberately admitted — refusing it would refuse most of the population at the one act R-8 says must stay available. The hole was D3's third state: a *claim* that cannot be graded. A reader could tell a checked `done` from an asserted one only by reading the note, and the DAG still advanced on the word.

## Fix
D5 (`redesign-plan/decisions.md`, 2026-08-19 morning interview): checkout REFUSES an unverifiable done; `done` = verified claim, always. The ruled wording "records 'exited, outputs unverified'" was already unwritable by a seat (`exited` is kit-only); `88f1b361` therefore reused `incomplete` with reason stamped `outputs-unverified: <the undeclarable note>` — no new enum value, same `checkout_disposition` expression, all three surfaces agree. Inside `cmd_checkout`, after the missing-output / open-owner-ask refusals: `if _outputs_note.startswith("outputs-undeclarable"): incomplete = f"outputs-unverified: {_outputs_note}"`. The WORD `done` is refused on stderr via `refusal_text("state", …)` naming LOOKED AT (the io-spec `## Outputs` block) and FOUND (zero resolvable path tokens). The seat is told its two remaining honest options: get the leader/materializer to declare real tokens (a seat cannot edit its own `seat.md` from inside the cage), or `--incomplete "<why>"` next time so the record carries the seat's reason.

Rejected: a hard refuse + exit 1 with no record. The cage denies write access to `seat.md`, so the seat cannot add the missing tokens; "Recording nothing is the 08-19 freeze made worse." Also rejected: refusing `none-declared` — that would refuse most of the population. The one-downgrade is loud, not silent: silently rewriting `done` into `incomplete` is barred for missing-output / owner-ask (kit declaring a fact only the seat can witness); D5 is the exception because the kit *did* witness the undeclarable surface. The closing "next:" hint is branched so an `outputs-unverified:` incomplete does not say "the run records that you said so" — "the seat did not say so. That lie is the class of record this gate exists to delete."

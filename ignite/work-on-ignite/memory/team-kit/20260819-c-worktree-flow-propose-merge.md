## Motivation
D4 (owner, 2026-08-19 morning alignment, `redesign-plan/decisions.md`) is one sentence: leader proposes a merge request, owner approves; nothing reaches any repo's main without the owner. The worktree tool P2 later adopted already existed: `a8a5e374` (2026-08-05) shipped `worktree-flow.py` with branches `goal/{slug}/integration` + `goal/{slug}/{seat}`, worktrees under `.rbtv/worktrees/`, `merge-seat` (Y→X in the integration worktree), and `close-goal` (delete X after it is already in main). That tool never composed an owner-facing request and never opened a PR; X→main was a docstring claim ("executed by the owner or by master — not by this tool") with no verb that handed the owner the request. ## Design

Four payloads share the commit because they are one door: `worktrees_root` / `all_worktrees_roots` implement P3's override from `{ws}/.rbtv/config/worktrees-self-root`; `gate_repo` sits at the top of `cmd_open_goal` / `cmd_open_seat` so a goal cannot open a worktree on a READ ONLY registry row (`E_READ_ONLY_REPO=7`) or on a repo absent from `goal.md`'s `repos:` key (`E_UNDECLARED_REPO=6`); `cmd_propose_merge` is the D4 verb and its docstring opens "This verb NEVER merges"; `close-goal --park` implements P2's preserve path by calling `remove_worktree` and never `delete_branch`. Seven seconds later `f636b212` (18:35:58Z) adds `worktreeScanRoots` in `spawn.js` so `resolveSeatGrants` walks both roots — without it a seat launched from a `5-workbench/…` worktree resolved an empty grant list, because the pre-change resolver only `readdir`'d `.rbtv/worktrees`.

Rejected, named in the module docstring extended in `7c829a91`: kernel-hard isolation via per-seat clones (R14, "deliberately not taken" — review, not the kernel, enforces branch discipline); the tool itself merging or pushing main; passing the merge-request body as an inline `coord.py` shell argument (file-based `--file` to avoid injection). Also rejected in the same commit: a silent "allow anything" fallback when `.artifacts/repos.md` is missing (one warning, then only the declaration gate); combining `--park` with `--force` (`E_PARK_FORCE=10` — preserve everything, or discard deliberately, not both). P2's rationale is why the 2026-08-05 tool was extended rather than rewritten. Seed docs around D4 name no further alternative for the merge-request mechanism itself.

## How it works
`worktrees_root(ws, repo)` returns `{ws}/.rbtv/worktrees` unless `repo` is the self repo (realpath equals workspace) AND the first non-empty line of `.rbtv/config/worktrees-self-root` names a workspace-relative directory; on this vault that file is `5-workbench/vault-worktrees`. `list` scans `all_worktrees_roots`. `gate_repo` parses READ ONLY backticked paths from `.artifacts/repos.md` and the `repos:` list from `goal.md` frontmatter (`_parse_repos_key`; `.` means the self repo). Then `propose-merge --repo PATH --goal SLUG [--main main] [--dry-run] [--body-out PATH]`: refuses missing X (`E_NO_X=8`) or `git rev-list --count {main}..{X}` == 0 (`E_NOT_AHEAD=9`); `compose_merge_request_body` writes the `diff --stat` and the exact `git merge --no-ff` the owner is expected to run. Self-repo OR no `github.com` in `origin` → `coord.py send owner --type escalation --file <path> --as leader`. Otherwise `git push -u origin {X}` then `gh pr create --base {main} --head {X} --body-file`. `--dry-run` prints those argv and returns. `close-goal --park` removes every `{root}/*--{goal}--*` worktree, prints each `goal/{slug}/*` as merged/UNMERGED against `--main`, and leaves the refs. Spawn side: `readWorktreesSelfRootRel` + `worktreeScanRoots` mirror the Python roots; a missing alternate directory is a `continue`, not an error.

## ATTENTION
- No scheduled probe asserts that `propose-merge` refuses to merge, routes bus-vs-PR, or rejects a missing/empty X. A regression there is visible only if someone runs `worktree-flow.py selftest`; `probe-suite.js` will stay green.
- `worktrees_root` / `all_worktrees_roots` in `worktree-flow.py` and `worktreeScanRoots` in `spawn.js` are two hand-kept copies of the same root list. Changing one without the other leaves a self-rooted seat with an empty grant list and no error — `resolveSeatGrants` treats a missing directory as ordinary.
- `cmd_propose_merge` composes a request and stops. The owner-facing body prints the `git merge --no-ff` the owner is expected to run by hand; if this verb starts merging or pushing main, nothing in the scheduled suite fails and D4's owner door is gone.
- `--park` and `--force` are exclusive (`E_PARK_FORCE`) because they are opposite intents: preserve every unmerged `goal/{slug}/*` ref, or discard. Teaching `--park` to delete branches would drop the P2 "never lose information" guarantee while still looking like a clean close.

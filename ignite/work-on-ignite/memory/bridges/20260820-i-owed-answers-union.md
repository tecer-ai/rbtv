## Mechanism
`coord.open_asks(..., to=owner)` filters `type == "ask"`. An escalation is `type == "escalation"` — the class that HALTS a goal on the owner — so it cannot appear in that set. `collect()` called only `open_asks`, then `render()` emitted the explicit empty string when the row list was empty. Widening `open_asks` itself would have been the one-line fix, but four check-out hold gates read that predicate live; a widened filter would let the escalating seat's own hold self-deadlock on its own escalation (ruling `p-owed-answers-locus`, stated in the `owed-answers.py` module docstring and cited by D30, not a numbered D-id). `packages()` also seeded `_channel-master` and then re-appended every `goals.csv` name, so once that package gained a row it was enumerated twice and every debt row in it was counted twice (broke `--selfcheck`). Slack owner text forwarded onto a goal-master channel had no durable side-channel, so `boot_prompt()` had nothing to fold in on the next daemon sitting (D75: never mint a sitting just to deliver; D24 stands). Seat 09's first `ask-store.js` stored one bare entry per seat, matching `thread-map.js`'s one-conversation-per-channel model — the second `createAsk` was a silent overwrite, not a queue.

## ATTENTION
- The owed-answers union must stay a CALL into `coord.open_asks`, never a widen of that predicate's filter: four check-out hold gates read `open_asks` directly, and a widened filter self-deadlocks the escalating seat at its own hold (ruling `p-owed-answers-locus`, in the `owed-answers.py` module docstring, not a numbered D-id).
- Any new reader of `{goalDir}/coordination/owner-asks.json` must accept both shapes — a D89 list, or a pre-`607014d4` bare object per seat — the same way `ask-store.js` `readStore`, `coord._owner_asks_entries`, and `collect_unanswered_asks` already do; a list-only reader silently drops or misparses files written before the queue commit.
- No caller yet passes `askId` to `markAnswered`, so it always settles the oldest open ask. A future per-ask-thread caller (Slack is one thread per goal conversation today; `coord --re` is staff-mail, a different bus) must pass `askId` or it will close the wrong ask when more than one is open.
- `ask-store.js` timestamps must stay in `coord.now()` form `YYYY-MM-DD HH:MM` (local, no seconds). An ISO timestamp silently ages as `?` on the Python side via `coord.age_of`.
- `_channel-master` is both hardcoded into `packages()` and present as a `goals.csv` row. The `name not in names` guard added in `61fc759f` is what stops every halt/ask in that package being counted twice; dropping the seed or the guard re-breaks `--selfcheck`.

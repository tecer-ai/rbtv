# Guide

A file under `guides/` that says how to build one standard rbtv file, folder, or [cognitive unit](cognitive-unit.md) well: what it is for, what a good one looks like, how to reach that, and, when a named source has shown one, the traps to avoid. The shape of every guide is the [guide template](../templates/guide.md). A file rbtv creates stays a few lines: what it is for, that it is not hand-written, and what a good one shows.

The one exception is [choosing what to build](../guides/choosing-what-to-build.md): it routes between kinds of unit rather than building one, so it does not use that shape. A guide does not compare kinds. Where a file goes, and what rbtv writes, is in [`rbtv.md`](../rbtv.md), not in the guide.

An agent opens a guide because an [index file](index-file.md) or another file points to it at the moment of building. A guide is not exposed as a [skill](skill.md), [rule](rule.md), [command](command.md), or [agent](agent.md).

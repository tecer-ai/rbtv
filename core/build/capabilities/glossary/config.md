# `config/`

The `.rbtv/config/` folder for all user-specific configuration that rbtv and its modules and components need to run in this installation, including the installer's record of what it installed, [`install.json`](install-json.md). A component keeps its configuration in a folder named after it, such as [`config/ignite/`](ignite-config.md). An installed agent's own configuration stays in its [agent folder](agent.md#installed-agent), and local components stay in [`mirror/`](mirror.md). A configuration file names the environment variable that holds a secret, such as a token, never the secret itself.

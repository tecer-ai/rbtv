# MCP server

A program that offers an agent extra actions through the Model Context Protocol, the standard way harnesses connect to outside programs, either running locally or reached at an address. A component supplies each MCP server as one file in its `mcp-servers/` folder, `<mcp-server>.json`, in rbtv's own format; the [rbtv command](rbtv-command.md) translates it into each harness's MCP server settings. It names the environment variables that hold its secrets, never the secrets. An MCP server is not a [cognitive unit](cognitive-unit.md): like a [tool](tool.md), it acts outside the context window. It has its own [exposure method](exposure-method.md), so it has its own folder.

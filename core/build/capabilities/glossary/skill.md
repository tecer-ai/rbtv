# Skill

A cognitive unit an agent chooses to use when relevant. The harness always shows its description to the agent; the agent reads the full instructions only when needed. An rbtv-format skill's source content lives under a component's `skills/` folder; rbtv creates a thin loader for each installed harness. A shareable [self-contained skill](self-contained-skill.md) instead lives in the mirror's `_skills/` folder and also gets a thin loader.

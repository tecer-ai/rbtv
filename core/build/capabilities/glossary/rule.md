# Rule

A cognitive unit whose full instructions reach every agent that receives it, on every task, with no choice to load them. It requires no activation by a human. The installer installs rules directly, without thin loaders: each installed copy is the rule's text with the installer's `rbtv-managed` banner. Claude Code reads it from its rules folder; Codex and OpenCode, which have none, get the full text in its own marked section of `AGENTS.md`.

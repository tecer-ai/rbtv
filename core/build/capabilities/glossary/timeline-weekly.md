# Weekly timeline

One file per ISO week, at `.rbtv/memory/timeline/weekly/<YYYY-Www>.md`, written only by the [dreamer](dreamer.md). It is the few events of the week that still matter, compressed from that week's [daily timeline](timeline-daily.md). It answers what happened that week. It is read on demand and never injected.

It links the owner's weekly periodic note and, per event, the daily file it comes from. It does not copy either.

# Component

A named unit within a module. It lives at `<module>/<component>/`, has a [`<component>.json`](component-json.md), and groups the cognitive units and capabilities, including tools, that belong together. Its source folders are [`skills/`](skill.md), [`rules/`](rule.md), [`commands/`](command.md), [`agents/`](agent.md#rbtv-agent), [`sub-agents/`](agent.md#harness-native-sub-agent), [`packs/`](pack.md), [`hooks/`](hook.md), [`mcp-servers/`](mcp-server.md), [`capabilities/`](capability.md), and [`folder-instructions/`](folder-instructions.md), from which it ships [folder instructions](folder-instructions.md) into target folders. Each skill, rule and command is one file, `<name>.md`. An rbtv agent is a folder, `agents/<name>/`, holding `agent.md` and `agent.json`. A harness-native sub-agent is one file, `sub-agents/<name>.md`. A pack is one file, `packs/<name>.json`. Each hook and MCP server is one file, `<name>.json`. A component has no [index file](index-file.md): its `<component>.json` describes it.

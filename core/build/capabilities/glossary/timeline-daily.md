# Daily timeline

One file per day of agent activity, at `.rbtv/memory/timeline/daily/<YYYY-MM-DD>.md`, written only by the [dreamer](dreamer.md). It is the episodes of that day's work between the owner and their agents, across agents. It answers what happened on that day. It is read on demand and never injected.

It links the owner's periodic note for that day and does not copy it. It is separate from those notes. A day with no agent activity has no file. A missing file means no activity, not a broken memory. Episodes point at the thread. They are not the only home of a durable fact: durable facts live in the [profile](profile.md), [knowledge](knowledge.md), or an [entity](entity.md).

# Folder artifact

A standard file that a folder can hold, named after that folder and serving one fixed purpose, such as the [index file](index-file.md), a component's [`<component>.json`](component-json.md), or a tool's [`<tool>.json`](tool-json.md). Folder artifacts give a folder a structure that agents can navigate, and they store configuration about that folder, as `<component>.json` does. Each kind of folder has its own set: rbtv's component and tool folders use the ones named here, while an agent folder, a project folder, a wiki, or a PARA folder has a set of its own. The naming pattern lets agents and programs find them in any folder. An agent reads a folder artifact by opening it when a pointer or the folder leads it there, and a program such as the [installer](rbtv-installer.md) reads it directly. Folder artifacts are [cognitive units](cognitive-unit.md). It is never exposed as a [skill](skill.md), [rule](rule.md), [command](command.md), or [agent](agent.md).

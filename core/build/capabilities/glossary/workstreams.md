# Workstreams

The map of everything active, at `.rbtv/memory/workstreams.md`. One line each for a project, an area, or an open agent-board subject: the name and where it lives. No state words and no detail. Boards hold the state. Copied state goes stale.

The [dreamer](dreamer.md) writes it. It is read on demand, from the [memory index](memory-index.md), and is not injected. Past 60 lines the owner is alerted. The file never refuses a line: the map must list what is active. A line leaves when its project is archived or its subject closes, and the run's commit records why.

# Task

One piece of work given to a human or an agent. It states its goal in ordinary language and supplies its [scope](scope.md) and [done contract](done-contract.md). A task can be given directly, in a conversation or by one agent invoking another, or saved to be done later in a task file. For an [Ignite agent](agent.md#ignite-agent), a Slack message or a timer supplies it. The agent's [prompt](prompt.md) applies across tasks; a task is the particular work.

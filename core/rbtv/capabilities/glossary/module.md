# Module

A top-level group of related components in rbtv's source. Each module has its own folder, `<module>/`, described by its [`<module>.json`](module-json.md):

- [`core`](core.md) holds rbtv's own operation, installation, configuration, and editing, and the software that manages, runs, launches, and connects agents.
- [`meta`](meta.md) holds how agents behave, communicate, plan, and coordinate work.
- Other modules hold their own subject areas.

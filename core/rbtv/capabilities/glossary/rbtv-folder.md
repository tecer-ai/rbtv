# `.rbtv/`

The folder the [`rbtv` CLI](rbtv-cli.md) creates in the installation root. It contains the component mirror, configuration, agents (each in its own folder, found by name in `.rbtv/agents/`), runtime data, and [general memory](memory.md). An agent may also live in any folder and is addressed by its path; `.rbtv/agents/` is searched only for names.

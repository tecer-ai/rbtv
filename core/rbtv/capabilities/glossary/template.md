# Template

A template is the part of a page that gives the layout of the file that page teaches an author to write. It uses placeholders for the choices the author must make. It is not a completed example, a separate file or a schema.

Include a template when the page governs an author-written file with a fixed layout. Put it in a code block in that page. Do not add one when there is no such file, and do not create a template for templates.

Use placeholders that name the required decisions. An author fills each one and removes none of the required structure. Do not fill the template with an invented component or task that later authors might copy unchanged. A small example may illustrate a particular choice; it does not replace the template or establish another layout.

When building from a template, follow the owning page to decide the content and check that no placeholders remain. A template specifies the layout; it does not replace the instructions for choosing what belongs in it.

A [schema](schema.md) describes fields that software validates. Where a record has a schema, that schema governs accepted fields and values. A prose template cannot make an unsupported field valid. Change the schema and its consuming program together when the accepted record changes.

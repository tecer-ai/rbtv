# Scaffolding

Everything an [agent](agent.md) is exposed to besides its prompt: the [cognitive units](cognitive-unit.md) it has (skills, rules, commands, folder instructions) and the [hooks](hook.md), [MCP servers](mcp-server.md) and [tools](tool.md) set up for it. The files that the [`rbtv` command](rbtv-command.md) writes for them are [generated files](agent.md#rbtv-agent) in the agent's folder, not scaffolding.

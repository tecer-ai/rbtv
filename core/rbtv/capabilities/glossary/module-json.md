# `<module>.json`

The [folder artifact](folder-artifact.md) holding each [module](module.md)'s record, named after the module: `<module>/<module>.json`. The `rbtv` command reads it for the module's description, which they show when listing modules. A module has no [index file](<../_under-evaluation/guides/folder artifacts/glossary/index-file.md>): this record describes it.

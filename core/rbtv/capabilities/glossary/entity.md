# Entity

Thin facts about one person, organisation, geographic place, or device the owner deals with, at `.rbtv/memory/entities/<people|orgs|places|devices>/<slug>.md`. The filename is the id. `places/` is geography only. The file points at the note that holds the content and does not copy it. People and organisation files carry aliases and link to the transcription glossary, which stays the transcription source.

Read on demand, through that kind folder's generated [index file](<../_under-evaluation/guides/folder artifacts/glossary/index-file.md>), or by search over `.rbtv/memory/`. The [dreamer](dreamer.md) writes it, from transcripts and the [inbox](inbox.md). An over-cap write is refused, never truncated; detail moves into the note this file points at.

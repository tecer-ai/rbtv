# Workspace memory

Private notes about a repository or workspace other people share, at `.rbtv/memory/workspaces/<slug>.md`. A shared repository cannot hold one person's private memory, so these notes have one home in general memory.

Ignite injects a file only when the turn's working directory is under one of its declared paths. Otherwise it is read on demand. The [dreamer](dreamer.md) writes it. Nothing here repeats what the repository's own docs already say. Cap: 3,000 characters. An over-cap write is refused, never truncated.

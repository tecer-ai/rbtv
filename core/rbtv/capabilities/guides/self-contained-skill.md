# Building a self-contained skill

A [self-contained skill](../glossary/self-contained-skill.md) keeps its instructions and supporting material together in a shareable standard skill.

## Purpose

Use it to import a skill written elsewhere, or to author a skill others can use directly. The [mirror guide](mirror.md) covers the local source that contains it.

## What good looks like

- The skill explains one ability and carries everything needed to use it, so sharing its source does not depend on rbtv-specific capabilities.
- Its description lets an agent decide when to read it before loading the full instructions ([Progressive disclosure](../principles/progressive-disclosure.md)).
- Supporting material has a stated purpose and stays with the skill ([Single source of truth](../principles/single-source-of-truth.md)).

## Making it good

Read the skill's instructions and supporting material together. Check that a reader can perform a representative task using only what the skill includes. If a dependency is external, name it in the skill.

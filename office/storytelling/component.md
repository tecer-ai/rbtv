# storytelling

Every deck, document, or site this module produces starts here. `narrative-lock` fixes the story
— audience, message, structure — before a single visual decision is made; `visual-strategist` then
turns that locked narrative into a plan for grouping content into slides, pages, or screens.
`research-brief` is the shared input both consume: four purpose-typed briefs (audience, market,
competitive, decision) that ground the narrative in something other than the writer's assumptions.

## Entry points

| Part | What it is |
|---|---|
| `capabilities/narrative-lock/narrative-lock.md` | Locks audience, message, and structure before any visual work starts. The one exposed narrative skill. |
| `capabilities/visual-strategist/visual-strategist.md` | Turns a locked narrative into a visual-communication plan — grouping into slides/pages/screens. |
| `capabilities/research-brief/research-brief.md` | The four-purpose-type research brief embedded inside narrative-lock and visual-strategist; no exposure row — reached only through them. |
| `references/ai-anti-patterns.md` | Tells-of-AI-writing checklist an agent loads before drafting narrative copy. |
| `references/tone-extraction.md` | Writing-voice extraction framework. |

Site and app narrative work are future workflows that reuse these same capabilities — not built in
this module.

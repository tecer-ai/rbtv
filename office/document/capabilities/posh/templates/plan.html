A seat plan is a set of self-contained work units ("seats"), each run by its own agent. Seats are grouped below into waves: a seat's wave is set by its dependencies — everything in wave 1 can start immediately; a seat in a later wave waits for the earlier seats it names. Statuses: pending not started · wip work in progress · done finished and verified · blocked stopped, reason on the card · ⚠ owner touchpoint needs a human decision or input.
